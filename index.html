Mis sonidos

Cada línea es una notita que se desliza de un tono a otro. Ej.: 988 988 70 y 1319 1319 300 hacen el sonido de una moneda. Una frecuencia 0 es silencio.

Paquete completo

Un ZIP con hoja de sprites, atlas, tileset, todos los niveles, fondos, el proyecto editable, una guía para Claude y un juego listo para abrir.

Llevar a Claude

Copia un texto con tus assets y el formato de los datos. Pégalo en un chat de Claude y pídele el juego, enemigos, niveles o mejoras.

Archivos sueltos

El juego .html necesita estar en la misma carpeta que los .png. Por eso el ZIP es lo más cómodo.

Importar proyecto

Carga un proyecto guardado, o el JSON que te devuelva Claude después de mejorarlo.

Proyectos del repositorio

Abre un proyecto guardado en la carpeta proyectos/ de este sitio: personajes, niveles y fondos que ya están en GitHub.

Para sumar uno nuevo: descarga «Proyecto .json (para el repo)», súbelo a proyectos/ y agrégalo a proyectos/index.json.
